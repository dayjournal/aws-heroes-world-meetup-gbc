## ダウンロード

[Releases](https://github.com/dayjournal/aws-heroes-world-meetup-gbc/releases)からゲームのZIPをダウンロードし、展開した`.gbc`ファイルを対応するエミュレーターや実機で読み込んでください。

## 遊び方

1. Game Boy Colorに対応する環境で`.gbc`ファイルを読み込みます。
2. タイトル画面で **START** を押し、**World journey** を選びます。
3. **Hero / AWS employee / Community** から参加方法を選びます。名前を入力する場合は **START** で決定します。
4. 世界地図から地域と国を選びます。
5. 会場を歩き、Heroの方を向いて **A** で話しかけます。

## 操作方法

| ボタン | 操作 |
| --- | --- |
| 十字キー | 移動・選択 |
| A | 話しかける・決定・扉を使う |
| B | メニューで戻る・移動中に押し続けると走る |
| START | メニューを開く |
| SELECT | 集合写真のメニューを開く |
